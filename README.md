# Hackerrank

This repository contains solutions and notes related to exercises completed on HackerRank.

Current contents:

- `javascript-basic-certificate/` — exercises and source files for the basic JavaScript track.

Purpose

- Store solutions, examples, and useful notes for reviewing or revisiting HackerRank exercises.

Prerequisites

- Node.js (any modern version). To check:

```bash
node -v
```

Running the files

- The files are standalone JavaScript scripts. To run them use Node:

```bash
node javascript-basic-certificate/country-codes.js
node javascript-basic-certificate/user-warning-data.js
```
